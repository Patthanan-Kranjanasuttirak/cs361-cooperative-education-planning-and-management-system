# cs361-cooperative-education-planning-and-management-system
cs361 Cooperative Education Planning &amp; Management System
Project Vision

**Primary User**
นักศึกษาชั้นปีที่3 ที่ต้องการสมัครเเผนสหกิจศึกษา ต้องการที่จะดูข้อมูล ข้อกำหนด เกณฑ์การสมัครเเผนสหกิจศึกษา เเละรายละเอียดข้อมูลสถานประกอบการในการตัดสินใจสมัครสหกิจศึกษา

**Problem**
นักศึกษาสามารถหาข้อมูลเกี่ยวกับสหกิจศึกษาได้ยาก ข้อมูลกระจัดกระจาย บางครั้งไปสอบถามอาจารย์ก็อาจจะได้คำตอบไม่ทั้งหมด

**V1 Goal**
ระบุว่าระบบจัดการแผนสหกิจศึกษา V1 สามารถให้นักศึกษาชั้นปีที่ 3 สามารถค้นหา ตรวจสอบข้อมูลแผนการฝึกสหกิจ และเกณฑ์ข้อกำหนดของโครงการสหกิจศึกษาได้ครบถ้วนจากจุดเดียว

**V1 In Scope**
- ดูข้อมูลรายละเอียด ขั้นตอน คุณสมบัติ กำหนดการ แนวทางการเตรียมตัวแผนสหกิจได้
- ดูข้อมูลสถานประกอบการบางส่วนที่เปิดเผยได้
- นักศึกษาเข้าถึงข้อมูลผู้ติดต่อเพื่อสอบถามข้อมูลเกี่ยวกับสหกิจศึกษาได้

**V1 Out of scope**
- ระบบสามารถเข้าสู่ระบบได้ตามบทบาทของผู้ใช้ได้ตามผู้ที่เกี่ยวข้องกับระบบ
- ระบบสามารถติดตามสถานะแผนสหกิจของนักศึกษา
- นักศึกษาสามารถส่งแผนสหกิจศึกษาตามสิทธิ์ของตนเองได้
- อาจารย์และเจ้าหน้าที่สามารถตรวจสอบและจัดการข้อมูลหรือควบคุมการเข้าถึงข้อมูลได้ 

**External actors**
- นักศึกษาสาขาวิทยาการคอมพิวเตอร์ที่สนใจหาข้อมูลเเผนสหกิจศึกษา 
- อาจารย์ หรือเจ้าหน้าที่ในสาขาวิทยาการคอมพิวเตอร์
- ผู้ประสานงานสถานประกอบการที่ให้หรือยืนยันข้อมูลสถานประกอบการที่สามารถเปิดเผยได้

**External System / Data Sources**
- ข้อมูลของสถานประกอบการที่เปิดเผยให้ระบบสามารถดำเนินการได้
- ข้อมูลหรือเกณฑ์ของแผนสหกิจศึกษา

**Assumptions**
- ผู้ใช้ต้องการเข้ามาเพื่อสืบค้นข้อมูล
- ข้อมูลแผนสหกิจไม่มีการเปลี่ยนแปลง
- ข้อมูลรายละเอียดของสถานประกอบการไม่มีการเปลี่ยนแปลง

**To Validate**
- มีรายละเอียด ข้อมูล เเละแนวการเตรียมตัวในการสมัครสหกิจศึกษา?
- มีสถานประกอบการกี่แห่งที่จะแสดงบนหน้าของเว็บไซต์?
