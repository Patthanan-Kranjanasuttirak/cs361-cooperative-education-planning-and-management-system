# cs361-cooperative-education-planning-and-management-system
cs361 Cooperative Education Planning &amp; Management System

**Project Vision**
สร้างระบบกลางสำหรับจัดการแผนสหกิจศึกษาของนักศึกษา ตั้งแต่ข้อมูลนักศึกษาและสถานประกอบการ การเสนอหรือเลือกแหล่งฝึก การสมัคร/พิจารณา การอนุมัติแผน การติดตามสถานะและกำหนดการ ไปจนถึงข้อมูลสรุปเพื่อสนับสนุนการวางแผนและติดตามในระดับหลักสูตรหรือสาขาวิชา

**V1 Information**
**Objective**
V1 มุ่งเน้นให้ผู้ใช้สามารถเข้าถึงข้อมูลพื้นฐานรายละเอียดเกณฑ์การรับสมัครสหกิจ เเละรายละเอียดสถานประกอบการที่ร่วมmouกับสาขาวิชา โดยยังไม่จำเป็นต้องเข้าสู่ระบบ

**V1 In Scope**
- ดูข้อมูลรายละเอียด ขั้นตอน คุณสมบัติ กำหนดการ แนวทางการเตรียมตัวแผนสหกิจได้
- ดูข้อมูลสถานประกอบการบางส่วนที่เปิดเผยได้
- นักศึกษาเข้าถึงข้อมูลผู้ติดต่อเพื่อสอบถามข้อมูลเกี่ยวกับสหกิจศึกษาได้

**V1 Out of scope**
- ระบบสามารถเข้าสู่ระบบได้ตามบทบาทของผู้ใช้ได้ตามผู้ที่เกี่ยวข้องกับระบบ
- ระบบสามารถติดตามสถานะแผนสหกิจของนักศึกษา
- นักศึกษาสามารถส่งแผนสหกิจศึกษาตามสิทธิ์ของตนเองได้
- อาจารย์และเจ้าหน้าที่สามารถตรวจสอบและจัดการข้อมูลหรือควบคุมการเข้าถึงข้อมูลได้ 

**Assumptions**
- ผู้ใช้ต้องการเข้ามาเพื่อสืบค้นข้อมูล
- ข้อมูลแผนสหกิจไม่มีการเปลี่ยนแปลง
- ข้อมูลรายละเอียดของสถานประกอบการไม่มีการเปลี่ยนแปลง

**To Validate**
- มีรายละเอียด ข้อมูล เเละแนวการเตรียมตัวในการสมัครสหกิจศึกษา?
- มีสถานประกอบการกี่แห่งที่จะแสดงบนหน้าของเว็บไซต์?

**Data Ownership / Source of Truth**
- เกณฑ์หรือข้อกำหนดการสมัครสหกิจ → เจ้าของข้อมูลคือเจ้าหน้าที่สหกิจศึกษา/สาขาวิชา
- ข้อมูลสถานประกอบการ → เจ้าหน้าที่สหกิจศึกษาเป็นผู้ดูแล โดยอ้างอิงจากผู้ประสานงานสถานประกอบการ


**Boundary**
**Inside the System**
- ดูข้อมูลรายละเอียด ขั้นตอน คุณสมบัติ กำหนดการ แนวทางการเตรียมตัวแผนสหกิจได้
- ดูข้อมูลสถานประกอบการบางส่วนที่เปิดเผยได้
- นักศึกษาเข้าถึงข้อมูลผู้ติดต่อเพื่อสอบถามข้อมูลเกี่ยวกับสหกิจศึกษาได้
  
**Outside the System**
-ระบบสามารถเข้าสู่ระบบได้ตามบทบาทของผู้ใช้ได้ตามผู้ที่เกี่ยวข้องกับระบบ
-ระบบสามารถติดตามสถานะแผนสหกิจของนักศึกษา
-นักศึกษาสามารถส่งแผนสหกิจศึกษาตามสิทธิ์ของตนเองได้
-อาจารย์และเจ้าหน้าที่สามารถตรวจสอบและจัดการข้อมูลหรือควบคุมการเข้าถึงข้อมูลได้

**External Actors**
-นักศึกษาสาขาวิทยาการคอมพิวเตอร์ที่สนใจหาข้อมูลเเผนสหกิจศึกษา
-อาจารย์ หรือเจ้าหน้าที่ในสาขาวิทยาการคอมพิวเตอร์
-ผู้ประสานงานสถานประกอบการที่ให้หรือยืนยันข้อมูลสถานประกอบการที่สามารถเปิดเผยได้

**External System / Data Sources**
-ข้อมูลของสถานประกอบการที่เปิดเผยให้ระบบสามารถดำเนินการได้
-ข้อมูลหรือเกณฑ์ของแผนสหกิจศึกษา

**System Boundary**
  
**Customer -> System**
ผู้ใช้สามารถ:
- คำค้นหา เช่น ตำแหน่งงาน สถานประกอบการ
- ตัวเลือกการกรองข้อมูล เช่น ช่วงเวลา สถานประกอบการ ตำแหน่งงาน
- คำขอเรียกดูรายละเอียดข้อมูลข้อกำหนดหรือกำหนดการ
  
**System -> Customer**
ระบบส่งข้อมูลให้ผู้ใช้ เช่น:
- รายละเอียด ขั้นตอน ข้อกำหนด และกำหนดการ
- รายการสถานประกอบการ
- ตำแหน่งงานที่รับสมัคร
  
**External Data Source -> System**
ระบบสามารถรับ:
- ข้อมูลและข้อกำหนดสหกิจศึกษา
- ข้อมูลสถานประกอบการบางส่วนที่เปิดเผยได้
- ข้อมูลกำหนดการ แนวทางการเตรียมตัว
